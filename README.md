# Simulador Didático de Urna Eletrônica

## Sobre o projeto
Projeto educacional que simula, de forma simplificada, um processo de votação eletrônica utilizando exclusivamente dados fictícios.

## Objetivo
Demonstrar conceitos de desenvolvimento web, autenticação, banco de dados, arquitetura MVC, segurança e testes.

## Tecnologias
- PHP
- MySQL
- HTML
- CSS
- JavaScript
- Git e GitHub

## Funcionalidades previstas
- Autenticação de eleitores fictícios
- Cadastro de candidatos e partidos fictícios
- Simulação de votação
- Confirmação de votos
- Apuração de resultados fictícios
- Bloqueio de segunda votação

## Organização
O projeto utiliza a arquitetura MVC, separando Models, Views e Controllers.
